# 빗썸 중간 티어 Gate — 사전등록 후 건당 <₩1M, 봇상시금지

Gate는 CODE 연동(2024-03)됐으나 빗썸에서 미활성 상태다. 주소 사전등록 7영업일 후 건당 <₩1M로 가능하며, 반복출금 감시 조항이 있어 봇 상시 파이프는 금지된다.

**근거**: "중간 티어 | Gate | CODE 연동(2024-03)됐으나 빗썸 미활성 → 주소 사전등록 7영업일 후 건당 <₩1M. 반복출금 감시 조항 → 봇 상시 파이프 금지"

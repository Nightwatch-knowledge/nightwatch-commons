# 진행률 단위 = 경로(9×8=72) 기준, 체인은 하위 축

진행률 단위는 경로(9거래소×8거래소=72) 기준이다. 체인은 경로 아래의 축이므로 같은 경로의 다른 체인은 진행률을 올리지 않는다.

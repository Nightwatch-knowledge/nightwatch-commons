# NightWatch Knowledge Commons

> English mirror translated from the Korean source on 2026-09-10. Korean is canonical; all numbers, dates, and links are identical to the source.

> Public tier. Contains only market-structure knowledge that can be graded against **settling reality** (exchange APIs, on-chain data, real transfers) — fees, deposit/withdrawal gates, chains, account modes, market measurements.
> 1 file = 1 node, `[[links]]` = edges. Open it in Obsidian and a graph appears. How an AI should read this is in [[CLAUDE]].
> Every figure carries an `as_of`. **Before acting, check the freshness table in [[INDEX]] first** — the cheapest corridor yesterday is not guaranteed to be the cheapest today. Live values come from the NightWatch API/MCP.
> Korean (canonical) edition: [[../README]].

Atom notes (1 fact = 1 note) are linked from each hub node's trailing `## Atoms` section. Convention = [[ATOMIZATION_SPEC]].

# Evaluation unit = (exchange × ticker) pair — A/B/C/X grades

The evaluation unit is not the exchange but the (exchange × ticker) pair (Robin correction, 2026-08-05). A=comparison group + execution / B=comparison group only, execution banned (price signal only) / C=observe / X=excluded. Inclusion is a data-ingestion procedure; since pair_gate auto-blocks on unknown_support, the data itself is the review.
